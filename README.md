# Dungeon Framework

> A dynamic 2D dungeon crawler powered by modular, data-driven room generation and custom JSON scripting.

[![Itch.io](https://img.shields.io/badge/Play%20on-Itch.io-red?style=for-the-badge&logo=itch.io)](https://riftworks-studios.itch.io/dungeon-framework)

---

## Overview

**Dungeon Framework** is an exploratory 2D dungeon crawler where every run is dynamically assembled from a pool of data-driven, easily customizable, rooms. Procedural layouts, puzzle mechanics, pushable crates, open chests, and gather loot to upgrade your character.

### Key Features
* **Dynamic Generation:** Procedural room orientations, rarity tiers, and probability rolls for room objects.
* **Puzzle & Room Mechanics:** Interact with pressure plates and levers to activate doors and chests.
* **Progression Loop:** Collect coins and goodies to trade for speed upgrades that let you traverse through the dungeon faster.
* **Modder-Friendly Engine:** Fully data-driven architecture using JSON files for room layouts, object parameters, and item creation.

## How to Play

Play the latest build in the browser or download on Itch.io:  
**[riftworks-studios.itch.io/dungeon-framework](https://riftworks-studios.itch.io/dungeon-framework)**

### Objective
Explore randomly generated rooms, solve puzzles, collect valuable loot, and escape the dungeon to upgrade your speed.

### Controls

| **Move Up** | `W` / `Up Arrow` |

| **Move Left** | `A` / `Left Arrow` |

| **Move Down** | `S` / `Down Arrow` |

| **Move Right** | `D` / `Right Arrow` |

| **Interact / Pick Up** | `F` |

| **Cycle Inventory Slot** | `Mouse Scroll Wheel` |
